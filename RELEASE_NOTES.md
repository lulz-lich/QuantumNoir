# Quantum Noir v0.1.0

Initial professional release of Quantum Noir.

## Highlights

- Case-file investigation interface.
- Five MVP quantum cases.
- Interactive user controls and measurement runs.
- Advanced browser-side numerical model layer.
- Exportable Markdown case reports.
- Canvas/SVG visualizations tied to computed observables.
- Scientific scope and physics model documentation.
- Vitest suite and GitHub Actions CI.

## Scientific Boundary

Quantum Noir uses compact educational models. The project does not claim to solve quantum gravity or reproduce full quantum field theory in curved spacetime.
