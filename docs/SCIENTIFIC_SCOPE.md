# Scientific Scope

Quantum Noir is an interactive conceptual visualization project. It is designed to make core ideas in quantum measurement and black hole information easier to investigate through case files.

## What The Project Does

- Uses simplified probability and state utilities.
- Uses density-matrix-inspired phase damping to visualize decoherence.
- Uses complementarity metrics to connect path information and interference loss.
- Uses a conceptual CHSH value to show how entanglement changes correlation strength.
- Uses normalized Hawking temperature and radiation flux as visual metaphors for horizon curvature.
- Uses a Page-curve-inspired turnover parameter for black hole information cases.
- Visualizes measurement, interference, entanglement, delayed choice, Hawking radiation, and information paradox concepts.
- Treats black hole modules as conceptual explorations.
- Uses Page-curve-inspired graphics to explain the information accounting problem.

## What The Project Does Not Do

- It does not solve quantum gravity.
- It does not simulate full quantum field theory in curved spacetime.
- It does not compute real black hole evaporation for a physical mass.
- It does not model real detector hardware.
- It does not make experimental claims.
- It does not replace a physics textbook, paper, or numerical research tool.

## Intended Tone

The project is intellectually serious but intentionally stylized. The noir investigation framing helps users ask better questions:

- What was measured?
- What record exists?
- Which probabilities changed?
- Which explanation is compatible with the evidence?
- Where does the simplified model stop?
