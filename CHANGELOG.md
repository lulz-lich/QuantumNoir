# Changelog

## 0.1.0 - 2026-05-05

### Added

- React + TypeScript + Vite application shell.
- Noir case-file interface for five MVP cases.
- Interactive experiment controls and investigator notebook.
- Advanced numerical model layer:
  - complex linear algebra
  - tensor products
  - density matrices
  - partial trace
  - von Neumann entropy
  - double-slit amplitudes
  - Bell/CHSH observables
  - Mach-Zehnder delayed-choice model
  - normalized Hawking evaporation and Page curve models
- Canvas and SVG visualizations connected to computed observables.
- Markdown case report export.
- Vitest coverage for quantum utilities and model behavior.
- Scientific scope and model documentation.
